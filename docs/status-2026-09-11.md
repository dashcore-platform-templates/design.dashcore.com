# design.dashcore.com, where it stands on 11 September 2026

## Why it exists

Design was the hard part of every Dashcore project and it started from nothing each time. Flux and the starter kit gave a base, but shells, type and colour still had to be built by hand, and AI-generated mockups came out generic because there was nothing specific for them to be specific about. Travis asked for one design framework for the fleet: fifteen sites that look and work the same, starting small, exporting JSON.

## What it is

A written standard, a constrained generator, and an adapter.

The standard fixes structure for every fleet app: two shells, type and spacing scales, colour roles with measured contrast, every Flux component free and Pro, one icon set, motion limits, fixed status colours. It is markdown in the repo and doubles as the generator's instructions.

The generator takes a two-sentence brief and returns only the seven decisions the standard leaves open: accent, neutral temperature, type pairing, radius, density, one motif, sign-in copy. Each comes with a one-line reason that cites the brief. The output is a JSON file and five live mockups: sign-in, shell, dashboard, settings, and every component.

The adapter is a Composer package. One command rethemes a Flux kit from the JSON, installs the two-panel sign-in and the standard's custom components, and swaps Lucide icons for Heroicons. Running it twice changes nothing.

## Where it stands

Version one is built, committed and tested locally: the standard (draft, not yet cut), the viewer, the generator on Fable 5.1 after a three-model comparison, and the adapter proven on a fresh kit and on a copy of Executive OS. Eight commits, 45 tests, static analysis clean. Local only, no GitHub remote yet. Everything is tracked on DAS-2016, DAS-2017 and DAS-2018.

The retheme of an existing app works with one command. Reapplying components to an existing app is a person's or an agent's job with the pack's migration checklist, about two to three days for an app of Executive OS's size, and has not been run yet.
